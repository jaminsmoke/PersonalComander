# Manual de usuario

Guía de **Personal Comander** para el camarero en sala. La release descargable actual es **v1.6**.

Commander es la app del teléfono: mesas, comanda (toque y voz) y cuenta profesional. No es el puesto del negocio (eso es Personal Bar) ni el registro de cuentas (eso es Identity, en el VPS).

| Sección | Qué cubre |
|---|---|
| [Instalación](instalacion.md) | APK, primer arranque y requisitos |
| [Board de mesas](mesas.md) | Plano, semáforo, salas y gestos |
| [Comandas](comandas.md) | Voz, táctil y ciclo de la comanda |
| [Carta](carta.md) | Productos desde Gestión |
| [Ajustes](ajustes.md) | TPV, copias y URL de Identity |
| [Cuenta y turno](cuenta.md) | Entrar, perfil, QR y Personal Bar |
| [FAQ](faq.md) | Preguntas frecuentes |

La documentación técnica (arquitectura, contratos LAN, modelo de datos) está en la pestaña **Técnica**.
